Personal Portfolio 🚀

This repository contains the source code for my personal portfolio website. The portfolio is built to present my technical skills, projects, and professional background in a clean, readable, and recruiter-friendly way.

The main focus of this project is simplicity, maintainability, and user experience rather than heavy visuals.

Tech Stack 🛠️
React with TypeScript
Vite for fast development and builds
Tailwind CSS for responsive and consistent styling
Framer Motion for smooth and subtle animations

Key Features ✨
Clean and modern UI with a consistent layout
Smooth scrolling and intuitive section navigation
Fully responsive design for desktop and mobile
Readable and well-structured component architecture
Optimised for performance and accessibility
Content designed with recruiters in mind

Project Structure 📁
The codebase follows a modular and organised structure to keep components reusable and easy to maintain. Styling is handled using utility-first CSS, and animations are kept minimal for better performance.

Live Preview 🌐
Portfolio: https://coded-by-adhil.github.io/portfolio/

Getting Started ⚙️
Install dependencies
npm install

Run the project locally
npm run dev

Build for production
npm run build

Purpose 🎯
This portfolio represents my approach to frontend and full-stack development, with a focus on clean design, scalable code, and real-world usability.
