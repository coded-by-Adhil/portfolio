# Adil P K — Portfolio

Personal portfolio of a full-stack PHP developer (Laravel, CodeIgniter, React) based in London.

**[View the live site](https://coded-by-adhil.github.io/portfolio/)**

![Portfolio preview](https://coded-by-adhil.github.io/portfolio/preview.png)

## About

The site presents my background, skills, and projects in a clean, readable layout. It favours clarity, maintainability, and usability over heavy visual effects, and the content is written for recruiters and hiring managers.

My experience is in building ERP, e-commerce, LMS, healthcare, and finance applications with Laravel, CodeIgniter, React, and MySQL. I built this portfolio in React and TypeScript to show the front-end side of that work.

## Tech stack

| Technology | Role |
|---|---|
| React + TypeScript | Component-based UI with type safety |
| Vite | Development server and production builds |
| Tailwind CSS | Utility-first styling and a consistent responsive layout |
| Framer Motion | Subtle animation, kept minimal for performance |
| GitHub Pages | Hosting |

## Features

- Single-page layout with smooth scrolling and section navigation
- Responsive design for desktop and mobile
- Modular, reusable components
- Restrained motion that supports the content instead of competing with it
- Open Graph and Twitter Card metadata, so shared links render a proper preview
- Descriptive page title and meta description for search and link sharing

## Getting started

Requires a current Node.js LTS release.

```bash
git clone https://github.com/coded-by-Adhil/portfolio.git
cd portfolio
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
